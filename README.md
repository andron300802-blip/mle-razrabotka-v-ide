# DataFrameReporter
## Описание проекта
DataFrameReporter - Python-класс для автоматизированного формирования отчетов о качестве и структуре таблицных данных с использованием библиотеки pandas.
Класс позволяет быстро получить общую информацию о датасете перед дальнейшей обработкой и анализом.
## Возможности
- Подсчет количества строк и столбцов.
- Определение количества и доли полных дубликатов.
- Вывод описательной статистики.
- Подсчет общего количества и доли пропущенных значений.
- Настройка формата вывода чисел и процентов.

## Установка и настройка стреды Python
1. Клонирование репозитория: 
   ```bash
   git clone <URL_репозитория>
   cd <Имя_папки_проекта>
   ```
2. Создание виртуального окружения: 
   ```bash
   python3 -m venv venv
   ```
3. Активация окружения:

   ```bash
   source venv/bin/activate
   ```
4. Установите необходимые библиотеки: 
    ```bash
    python -m pip install -r requirements.txt
    ```
## Запуск программы
Из корневой директории проекта выполните:
```bash
python3 main.py
```
Программа загрузит датасет data/payments.csv, создаст объект класса DataFrameReporter и выведет отчёт в терминал.
